# 情绪星星瓶桌面多界面返工设计

## 目标

重做为桌面端单页多界面情绪管理网页。首页以立体星星瓶为唯一视觉核心，用户可以写入星星、随机拆开一颗待解决星星，或查看已解决记录。取消手机版软件、安装入口和一页三栏堆叠布局。

视觉延续参考图的深蓝星空、粉紫柔光、立体玻璃、彩色折纸星星和温暖猫咪陪伴感，但界面结构以已确认的多视图流程为准。

## 信息架构

应用包含四个视图，通过应用内部转场切换，不整页刷新：

1. 星星瓶首页
2. 写入星星
3. 随机拆开与解决
4. 已解决记录

所有次级视图均有明确的返回首页入口。首页不放表单和记录列表，只展示核心瓶子与入口。

## 首页

- 顶部显示产品标题、简短陪伴文案和猫咪陪伴角色。
- 页面中央展示大型立体玻璃瓶。
- 瓶内星星由真实待解决数据生成，数量、颜色和堆叠状态随数据变化。
- 星星具有轻微漂浮、呼吸和闪光效果。
- 瓶子下方显示实时待解决数量。
- 主入口为“写入一颗星星”。
- 次入口为“随机拆开一颗”。
- 右上角提供“已解决记录”入口。
- 空瓶时随机拆开入口禁用，并显示等待第一颗星星的空状态。

## 写入星星视图

第一阶段显示事件标题、生气原因、情绪强度和情绪颜色。原因不能为空。

点击“开始折星星”后：

1. 表单淡出并收起。
2. 纸条在中央逐步折成立体星星。
3. 用户点击“放进瓶子”。
4. 星星沿弧线飞入瓶口。
5. 数据写入本地存储，待解决数量增加。
6. 显示成功反馈并允许返回首页。

动画执行期间禁用重复提交。

## 随机拆开与解决视图

进入视图时只从待解决星星中随机选择一颗。瓶子先轻微摇动，随后星星飞出并展开成纸条。

纸条显示：

- 事件标题
- 生气原因
- 情绪强度
- 情绪颜色
- 创建时间

用户可以：

- 选择“暂时还没解决，放回瓶子”，纸条重新折叠并飞回首页瓶子，数据保持不变。
- 选择“我已经解决了”，展开解决方法输入区。
- 填写非空解决方法后点击“消除这颗星星”，星星发光并化为星尘。

消除完成后，该记录从待解决集合移动到已解决集合，保存解决方法和解决时间。

## 已解决记录视图

- 顶部显示累计解决数量和成长反馈。
- 记录使用星星卡片排列，颜色继承创建时的情绪颜色。
- 卡片摘要显示标题、原始原因、创建时间和解决时间。
- 点击卡片展开完整解决方法。
- 支持按最近解决和情绪颜色筛选。
- 记录不可直接删除，也不能重新放回待解决瓶子。
- 空状态显示猫咪抱着星星的陪伴插画和引导文案。

## 动效与视觉

- 视图切换使用淡入、水平滑动和星光粒子过渡。
- 写入流程包含纸条折叠、星星弹性成形和弧线飞入瓶口。
- 随机拆开包含瓶子摇动、星星飞出、纸条展开。
- 解决流程包含发光、缩小、星尘消散。
- 尊重 `prefers-reduced-motion`，减少动画时保留清晰的状态变化。
- 图标使用统一图标资源，避免将表情符号当作核心图标。

## 数据模型

每颗星星包含：

- `id`
- `title`
- `reason`
- `intensity`
- `color`
- `createdAt`
- `status`: `pending` 或 `resolved`
- `solution`
- `resolvedAt`

数据保存在当前浏览器本地存储中，不上传网络。刷新或重新打开页面后恢复状态。

## 异常与边界状态

- 原因为空时禁止进入折星阶段并聚焦输入框。
- 没有待解决星星时禁止随机拆开。
- 解决方法为空时禁止消除并保留当前展开状态。
- 本地存储读取失败时回退为空状态并显示非阻塞提示。
- 动画执行期间锁定重复操作。

## 验收标准

- 首页不出现创建表单、解决表单或记录列表堆叠。
- 四个视图均可通过明确控件进入和返回。
- 写入、折叠、飞入、随机抽取、放回、解决、消散和记录展开形成完整闭环。
- 待解决数量和瓶内星星实时一致。
- 刷新后数据保持。
- 空瓶、非空瓶、暂未解决、已解决和记录空状态均正确。
- 键盘可以完成主要操作，焦点状态清晰。
- 浏览器控制台无错误。
- 视觉验收以用户提供参考图的材质、配色和氛围为基准，同时服从本设计已确认的多视图结构。
