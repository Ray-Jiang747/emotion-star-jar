# 四步动态折星视觉优化

## 目标

把当前静态三步折叠图升级为更清晰、更可爱、更有动感的四步过程，同时与新版立体星星、夜空背景和 Kitty 装饰保持一致。

## 视觉结构

折叠阶段依次呈现四个独立状态：粉色纸条、第一次折角、收紧成星形、完成的可爱星星。四个状态横向排列，尺寸逐步增大，使用柔和发光箭头连接。成品必须复用 `origami-star-cute.png` 的大眼睛、腮红和开口笑形象。

## 动效

进入折叠阶段后，四个状态按顺序淡入、上浮并亮起；连接箭头同步产生从左向右的光流。最后一颗星星使用轻微弹跳和呼吸悬浮，减少动效设置下全部静态呈现。动画只负责表达进度，不改变写入和持久化逻辑。

## 布局与可用性

折叠卡片保持桌面版居中，四步内容在紧凑桌面宽度下仍完整可见。步骤下方增加简短标签“纸条 / 折角 / 收紧 / 完成”，不把说明文字烘焙进图片。保留“放进瓶子”主按钮、键盘焦点与现有交互锁。

## 验收

- 四个步骤和三个连接关系清楚可读。
- 新星星与首页瓶中星星为同一视觉语言。
- 动画顺序自然，不出现遮挡、裁切或横向滚动。
- `prefers-reduced-motion` 下无连续动画。
- 写入、放进瓶子、成功返回和本地持久化行为不变。
